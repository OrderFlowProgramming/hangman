# Raad Wie Ik Ben - Interactief Galgje

Een creatieve sollicitatie in de vorm van een galgje-spel. Raad het woord en ontdek wie ik ben!

## Features

- Klassiek galgje met een twist: je kan niet verliezen
- Hint-rad met persoonlijke eigenschappen
- DISC-profiel integratie
- Responsive design

## Technologie

- React + Vite
- CSS3

## Installatie

```bash
npm install
npm run dev
```
